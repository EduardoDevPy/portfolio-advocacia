# Landing Page — Dra. Maria Isabella Gomes

Landing page profissional desenvolvida para a advogada **Dra. Maria Isabella Gomes**, especializada em Direito do Consumidor, Direito do Trabalho e Direito Civil.

## Sobre o projeto

Site institucional com foco em conversão, desenvolvido para apresentar os serviços da advogada e facilitar o contato direto via WhatsApp. O design segue uma paleta sóbria e elegante, com tons escuros e detalhes dourados que transmitem credibilidade e autoridade.

## Seções

- **Hero** — Apresentação principal com chamada para ação e foto da advogada
- **Direitos** — Situações em que o consumidor pode estar sendo lesado
- **Serviços** — Áreas de atuação detalhadas
- **Como Funciona** — Processo simplificado em 4 etapas
- **Sobre** — Perfil e diferenciais da Dra. Maria Isabella
- **CTA** — Chamada final para contato via WhatsApp
- **FAQ** — Perguntas frequentes

## Tecnologias

- [React](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vitejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [shadcn/ui](https://ui.shadcn.com/)
- [Lucide Icons](https://lucide.dev/)

## Como rodar localmente

```bash
# Instalar dependências
npm install

# Rodar em desenvolvimento
npm run dev

# Build para produção
npm run build
```

## Deploy

O projeto está hospedado na [Vercel](https://vercel.com/) com domínio personalizado em [dramariaisabella.com.br](https://dramariaisabella.com.br).
